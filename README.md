# LeetCode Practice

A working repository for LeetCode and data-structure practice.

This repo is partly a record of solved problems and partly a reference list for future practice. Only problems marked with a checkmark currently have a corresponding implementation in `src/`.

## Status key

- ✅ Implemented in `src/`
- 🟨 Learning implementation / attempt, with limitations noted
- 🚧 Scratch, helper, or not counted as solved
- ⬜ Reference/backlog item to return to later
